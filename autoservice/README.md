# ТехБокс — демо-сайт автосервиса

Демо-сайт автосервиса по мотивам [autoservisdemo](https://github.com/vspider911/autoservisdemo). Сделан на чистом HTML, CSS и JavaScript без сборки и зависимостей. Есть мини-бэкенд на Node.js, но и без него сайт работает полностью.

Дизайн новый: тёмная «гаражная» палитра с сигнальным оранжевым, полосы-«зебры», шрифты Oswald, Inter и IBM Plex Mono. Как и в референсе, название, контакты, часы и цвет подставляются из ссылки.

## Что на сайте

- **Первый экран:** фото во весь экран, статус «Открыто / Закрыто» по московскому времени, плашка с рейтингом, часами, гарантией и опытом.
- **«Что беспокоит?»:** выбираете симптом («скрипят тормоза», «горит Check Engine»…), сайт подсказывает вероятную причину, срочность и нужные работы с ценой. Одной кнопкой работы попадают в калькулятор или в запись.
- **8 услуг** с ценами «от». Клик по карточке открывает нужную вкладку калькулятора.
- **Калькулятор:** вкладки, класс автомобиля (легковой ×1, кроссовер ×1,2, премиум ×1,5), итоговая сумма и время в боксе, удаление позиций из сметы.
- **Онлайн-запись:** 7 дней и слоты по 30 минут, у каждого дня видно число свободных слотов. Есть маска телефона. Работы из калькулятора переносятся в заявку. После записи клиент получает номер заказа. Если указан WhatsApp, заявку можно продублировать туда.
- **Статус ремонта:** по номеру заказа и последним 4 цифрам телефона показывается таймлайн «принята → подтверждена → в работе → готово → выдана». Демо-заказ: **№ 1000 и 0000**.
- **Как работаем**, бегущая строка марок, отзывы (примеры), FAQ, контакты с маршрутом, CTA.
- **Кабинет мастера** (`admin.html`, пароль `demo`): список записей, поиск, фильтр, смена статуса (клиент сразу видит её в трекере) и сводка: всего записей, записей на сегодня, новых и сумма по сметам.
- Адаптивная вёрстка с мобильным меню и нижней панелью «Позвонить / Записаться». Учтены `prefers-reduced-motion`, работа с клавиатуры и скринридер.

## Запуск

**С бэкендом** (записи хранятся на сервере, админка видит заявки со всех устройств):

```bash
cd autoservice
node server.js
```

Затем откройте http://localhost:3000. Порт и пароль админки задаются так: `PORT=8080 ADMIN_TOKEN=secret node server.js`.

**Без бэкенда:** выложите папку на любой статический хостинг (GitHub Pages, Vercel, Netlify) или откройте `index.html`. Сайт сам заметит, что API нет, и будет хранить записи в `localStorage` браузера. Запись, трекер и админка работают, но только в пределах одного браузера.

## API (server.js)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | проверка сервера |
| GET | `/api/slots?date=YYYY-MM-DD` | занятые слоты дня |
| POST | `/api/bookings` | создать запись: проверяет часы работы, телефон и занятость слота, ограничивает частоту запросов |
| GET | `/api/bookings/:id?phone=1234` | статус заказа (нужны 4 последние цифры телефона) |
| GET | `/api/admin/bookings` | все записи, заголовок `X-Admin-Token` |
| PATCH | `/api/admin/bookings/:id` | сменить статус `{ "status": "in_work" }` |

Записи сохраняются в `data/bookings.json` (папка в `.gitignore`). Файлы `server.js`, `package.json` и папка `data/` наружу не отдаются.

## Параметры ссылки

```
index.html?name=QuickMade&phone=84951254014&wa=79859272222&address=1-й Кирпичный пер., 4&metro=Семёновская&rating=4,8&votes=702&open=9&close=21&color=e63946
```

| Параметр | Что это | Пример |
|---|---|---|
| `name` | название | `QuickMade` |
| `phone` | телефон, любой формат | `84951254014` |
| `wa` | WhatsApp, только цифры | `79859272222` |
| `tg` | Telegram без @ | `quickmade` |
| `address` / `metro` / `city` | адрес, метро, город | `ул. Ленина, 5` |
| `open` / `close` | часы работы | `9` / `21` |
| `days` | режим словами | `ежедневно`, `пн–сб` |
| `rating` / `votes` | рейтинг и число оценок | `4,8` / `702` |
| `map` | ссылка на карточку в Яндекс Картах | |
| `color` | цвет акцента без # | `ff5a1f` |
| `brands` | марки через запятую | `Kia, Hyundai` |
| `since` / `boxes` | год открытия, число постов | `2014` / `4` |

Значения по умолчанию, прайс (с временем работ), классы авто и подсказки по симптомам задаются в `config.js`. Сервер берёт часы работы из того же файла. Если поменять `open`/`close` в ссылке, это изменит только отображение, а не проверку на сервере.
