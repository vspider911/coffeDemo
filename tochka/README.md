# ТОЧКА — автосервис (демо)

Демоверсия сайта автосервиса на чистом HTML, CSS и JavaScript, без библиотек и сборки.
Запуск — откройте `tochka/index.html` в браузере.

- `index.html` — разметка: шапка, первый экран, услуги, тёмная секция «О сервисе», калькулятор, этапы, контакты, окно записи.
- `styles.css` — переменные, адаптивная типографика через `clamp()`, сетки, мобильная версия, `prefers-reduced-motion`.
- `script.js` — мобильное меню, навигация с учётом высоты шапки, список услуг, калькулятор, окно записи с проверкой полей и удержанием фокуса, появление элементов при прокрутке.

Компания, адрес, телефон и почта вымышлены. Форма записи ничего никуда не отправляет.
